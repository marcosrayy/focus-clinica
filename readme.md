# Focus Clínica 

Aplicativo desenvolvido para facilitar a experiência do cliente no atendimento e agendamento de consultas da Clínica Focus. 

## Sobre o Projeto 

A Focus Clínica é uma aplicação voltada para clientes de uma clínica particular, permitindo consultar informações, visualizar profissionais, verificar horários disponíveis e realizar agendamentos de formas simples e organizada. 

## Objetivo

O objetivo da Focus Clínica é oferecer uma interface simples, intuitiva e responsiva para que o cliente consiga realizar suas principais ações sem depender de processos manuais.

Entre as principais ações estão:

- Visualizar profissionais 
- Consultar horários disponíveis 
- Realizar agendamentos
- Visualizar consultas 
- Gerênciar seus agendamentos
