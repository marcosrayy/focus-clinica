Aplicativo desenvolvido para facilitar a experiência do cliente no atendimento e agendamento de consultas da Clínica Focus. 

## Sobre o Projeto 

A Focus Clínica é um SaaS voltado para clientes de uma clínica particular, permitindo consultar informações, visualizar profissionais, verificar horários disponíveis e realizar agendamentos de formas simples e organizada. 

## Objetivo

O objetivo da Focus Clínica é oferecer uma interface simples, intuitiva e responsiva para que o cliente consiga realizar suas principais ações sem depender de processos manuais.

Entre as principais ações estão:

- Visualizar profissionais 
- Consultar horários disponíveis 
- Realizar agendamentos
- Visualizar consultas 
- Gerênciar seus agendamentos

## interface do cliente 

Esse SaaS foi pensado e desenvolvida para proporcionar uma experiência simples e intuitiva aos clientes da Focus Clínica.

## Principais telas

- Tela inicial
- Login e Cadastro 
- Perfil do Cliente 
- Horários disponíveis 
- Agendamentos de consultas 
- Minhas Consultas 
- Detalhes da consulta

## Fluxo do Cliente 

1. O Cliente acessa o aplicativo 
2. Realiza seus Login ou Cadastro 
3. Seleciona Novo Agendamento
4. Escolhe a área da consulta 
5. Selecione a data
6. Confirma o agendamento 
7. O sistema exibe a confirmação da consulta
